  🚀 DEPLOY TO VERCEL (GET LIVE URL)
═══════════════════════════════════════════════════════════════════

FASTEST METHOD (1 minute):

1. Open PowerShell or Terminal

2. Run these commands:
   npm install -g vercel
   vercel login
   cd krishi-drishti
   vercel --prod

3. Follow prompts (press Enter for defaults)

4. Get your live URL!
   Example: https://krishi-drishti-xyz.vercel.app

5. Share this URL in your hackathon submission!


ALTERNATIVE: Push to GitHub first

1. Create repository on GitHub.com
   Name: krishi-drishti-sih2026

2. Run these commands:
   cd krishi-drishti
   git remote add origin https://github.com/YOUR_USERNAME/krishi-drishti-sih2026.git
   git branch -M main
   git push -u origin main

3. Go to vercel.com → Import Project
4. Select your repository
5. Click Deploy
6. Done!

  🛠️ IF SOMETHING'S NOT WORKING
═══════════════════════════════════════════════════════════════════

PROBLEM: Browser didn't open
SOLUTION: Manually open http://localhost:3000

PROBLEM: Page won't load
SOLUTION: Wait 30 seconds, then refresh (Ctrl+R)

PROBLEM: 3D view shows black screen
SOLUTION: This is NORMAL on some computers without GPU
         It will work perfectly on other devices!
         Try different browser (Chrome recommended)

PROBLEM: Want to restart server
SOLUTION: Open PowerShell in krishi-drishti folder
         Press Ctrl+C to stop
         Run: npm run dev

PROBLEM: Port 3000 busy
SOLUTION: npm run dev -- -p 3001
         Then visit http://localhost:3001
